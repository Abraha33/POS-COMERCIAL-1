# Contrato UI — Accesibilidad financiera

**Estado:** propuesta WCAG 2.2 AA; requiere prueba para declararse PASS.

- Todo importe, saldo, diferencia y estado de pago tiene etiqueta y formato legible.
- El resultado de un comando anuncia éxito, rechazo, pendiente o incierto sin depender
  solamente de color.
- Los diálogos de desembolso, cierre y reverso atrapan foco, explican consecuencia y
  devuelven foco al disparador.
- La captura de evidencia ofrece alternativa de archivo, vista previa con texto y
  posibilidad de eliminar antes de enviar.
- Conteo por denominación se opera íntegramente con teclado, lector y táctil.
- Tablas de conciliación exponen encabezados, selección, filtros y detalle a lector.
- Una diferencia, pago incierto o cuenta no configurada tiene rol de alerta y acción
  recuperable.
- Objetivos táctiles son de al menos 44 px y el zoom no oculta el CTA ni los totales.
