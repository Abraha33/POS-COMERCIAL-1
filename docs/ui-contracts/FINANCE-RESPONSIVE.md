# Contrato UI — Responsive financiero

**Estado:** propuesta; objetivo 1366, 768 y 375 px.

| Región | Desktop | Tablet | Teléfono |
|---|---|---|---|
| Contexto monetario | fila completa | fila compacta | bloque fijo superior resumido |
| Lista y detalle | dos columnas | panel colapsable | lista y detalle en navegación progresiva |
| Wizard de dinero | panel lateral | diálogo ancho | pantalla completa |
| Conteo | denominaciones + resumen lateral | dos bloques apilados | una denominación por fila, total fijo |
| Conciliación | tabla con detalle | tabla con scroll indicado | tarjetas con filtros y detalle separado |
| Acciones | barra visible | barra compacta | CTA fijo, acciones secundarias en menú |

No ocultar saldo, estado incierto, origen/destino ni confirmación para ahorrar espacio.
Las tablas deben tener estrategia explícita de tarjetas o scroll horizontal accesible;
no se acepta desborde invisible.
